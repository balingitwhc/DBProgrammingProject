# 🚀 Inventory System (WindowsForms)
A Visual Studio developed Inventory system using Windows form. Includes Employee login and verification, and Inventory database.

---

## ✨ Features
* Employee Login
* Splash/Loading Screen
* Employee, Products, and Inventory Sections
* Maintenance Section
* Windows Positioning and Status Bar
* Help Information
